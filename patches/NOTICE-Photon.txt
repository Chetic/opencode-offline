The adjacent @silvia-odwyer%2Fphoton-node@0.3.4.patch modifies photon_rs.js:
- Uses a dedicated object for WebAssembly import bindings instead of binding
  them to the changing CommonJS export object.
- Allows an explicit embedded WebAssembly resource path for Bun compiled
  executables, while retaining the package-relative resource fallback.
